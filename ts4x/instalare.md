# Desktop & Mobile Installation

::: warning Under development
TS4X is under active development. Download and installation steps will be published here when the release is available.
:::

TS4X runs standalone on desktop and mobile. No special hardware is needed.

## System Requirements

| Component | Minimum | Recommended |
|---|---|---|
| **Processor** | Intel x86_64 or ARM Cortex-A72 | Apple Silicon (M1/M2/M3) or 3nm-class processor |
| **Memory** | 8 GB RAM | 16 GB RAM |
| **Storage** | 256 GB SSD | 512 GB NVMe SSD, for fast patch loading |
| **Audio output** | 24-bit / 192 kHz stereo DAC | Native multi-channel USB audio interface |
| **Wireless** | | Bluetooth 5.0 |

## Platforms

TS4X targets Windows, macOS (Apple Silicon), Linux and Android.

## Optional Hardware

The [i-volution controller](/i-volution/) is optional. Any MIDI controller works with TS4X.

## Account

TS4X uses your iMIDI account. Cloud sync and licensing are linked to it. See [mySpace Account Setup](/cloud/).
