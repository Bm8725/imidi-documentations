# i-VOLUTION User Manual

Welcome to the official guide for the **i-VOLUTION MIDI System for Accordion**, a professional-grade MIDI integration built specifically for accordionists, on stage and in the studio.

## About i-VOLUTION

i-VOLUTION is a universal MIDI controller purpose-built for accordion. It provides velocity-sensitive MIDI mapping for the **SOLO** and **BASS** sections on any MIDI channel.

- **Manufacturer:** [iMIDI](https://www.imidi.co.uk)
- **Display:** 1.8" OLED with a single multifunction digital encoder and intuitive menu
- **Latency:** ultra-low, tuned for live performance
- **Firmware:** no updates required, works out of the box
- **Warranty:** 2 years


## Key Features

### Bellow Real Emulation
EMA (Exponential Moving Average) filtering delivers smooth, realistic pressure response with minimal sensor noise. The feel is close to Advanced Physical Behavior Modeling (APBM).

### Ultra-Low Latency MIDI
MIDI communication tuned for live use, with no lag between bellows and sound.

### Broad Synth Compatibility
Works with major digital synths, including the **KORG PA series** and **TS4X**.

### Efficient Power Design
TPS63061 power management provides long battery life.

### 1.8" OLED Display
Real-time readout of bank, bellows expression, volume and transpose, all controlled through a single encoder.

## MIDI Mapping

| Function | Details |
|---|---|
| **Transpose** | General MIDI via SysEx |
| **Compatible with** | KORG PA series, TS4X |
| **Performance Change** | Up to 11, via registers |
| **Bank Select** | A, B, C, D (default) + L (BASS), up to 127 (saves 11×127) |
| **Volume Control** | CC07 |
| **Expression Bellows** | CC11 |

## FAQ

**Do I need to update the firmware?**
No. The system works out of the box.

**Which synths is it compatible with?**
Major digital synths, explicitly including KORG PA and TS4X. It uses General MIDI over SysEx for transpose and standard CC07/CC11 for volume and bellows expression.
